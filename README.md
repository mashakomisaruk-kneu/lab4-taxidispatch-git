# lab4-taxidispatch-git

Навчальний репозиторій до лабораторної роботи №4 з дисципліни «Інформаційні системи і технології в управлінні».

## Предметна область
**ІС TaxiDispatch** — інформаційна система диспетчерської служби таксі для обліку замовлень і розподілу водіїв.

## Структура репозиторію
- `README.md` — опис проєкту та інструкція.
- `index.html` — базова вебсторінка АРМ диспетчера TaxiDispatch.
